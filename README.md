# AWS S3 File Manager using Python

## Description
A simple Python project that manages files in Amazon S3 using AWS SDK (Boto3).

## Technologies Used
- Python
- AWS S3
- Boto3

## Features
- Upload files to S3 bucket
- Download files from S3
- List files stored in S3

## Setup

1. Install dependencies:

pip install -r requirements.txt

2. Configure AWS:

aws configure

3. Update bucket name in app.py

4. Run:

python app.py

## AWS Services Used
- Amazon S3
- IAM
